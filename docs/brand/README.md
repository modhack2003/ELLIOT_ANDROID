# ELLIOT README artwork

The hero was generated with the built-in imagegen tool for this repository.

The README also uses original procedural visuals with the same midnight, cyan, and lavender palette.

| Asset | Purpose |
| --- | --- |
| [Signal loop](elliot-signal.gif) | A 4.8-second decorative waveform animation made from synthetic frames. |
| [Voice pipeline](voice-pipeline.svg) | A static diagram of standard and optional calibrated audio routing. |
| [Speech modes](speech-modes.svg) | Three selectable Whisper language settings with an accuracy-evaluation note. |

The SVGs are self-contained and include text descriptions. The README preserves textual explanations alongside the graphics. The screenshots under `docs/ui/0.6.2` are the existing Compose renders.

## Hero generation prompt

> Use case: stylized-concept. Asset type: ultrawide GitHub README hero for ELLIOT, an Android voice companion. Create a high-end editorial launch banner, wide landscape ratio 2.5:1 or wider. Exact text ‘ELLIOT’ in huge clean white geometric type on the left, with a single small line ‘VOICE COMPANION FOR ANDROID’ beneath, set on matte midnight navy. On the right, a deep-black translucent spherical voice orb suspended above thin concentric cyan sound rings, asymmetric sparse lavender reflections and an intricate luminous teal waveform that threads into the orb. Premium industrial design photography meets scientific instrument, precise minimal composition, restrained cyan/blue light, readable at small scale. Keep at least 9% margin on all sides. No phone screen, extra text, logos, stars, watermark, dashboard, or invented UI.
